What I Built

เว็บนี้ผมทำมาเพื่อแนะนำตัวเอง ทดลองวิชาที่เรียนมา และหาคะแนนวิชา CS100 (เอาไว้ส่งต่อรอยยิ้มด้วย :D)

ส่วนประกอบสำคัญ

  • มี Header สุดโดดเด่นที่บ่งบอกถึงจุดประสงค์ของเว็บไซต์
  • พาร์ทแนะนำตัวที่มีการใช้ถ้อยคำเป็นกันเองเพื่อความผ่อนตลาย
  • หัวข้อที่บ่งบอกถึงเหตุผล วิธีการทำ และผลลัพท์จากการทำเว็บไซต์นี้

วิเคราะห์สถาณะ Client / Server

ผมคิดว่ามีทั้ง client , server เกิดขึ้นแล้วโดยจะมี local server ถูกสร้างบนเครื่องเพื่อให้รันไฟล์
ได้เหมือนการทำงานบนเว็บจริง และ tab live preview เป็น client

Reflection

ปัญหาหรือความท้าทายที่พบและการแก้ไข

นึกภาพของการตกแต่ง website ที่อยากได้ออก แต่เขียน code ให้ภาพในหัวเป็นจริงไม่ได้
แก้ปัญหาโดยการ อ่านชีทเรียน และปรึกษา AI เพื่อหาคำแนะนำสำหรับขั้นตอนที่จำเป็น

สิ่งที่เข้าใจเกี่ยวกับการพัฒนาเว็บไซต์มากขึ้น

การเขียนแบบ freestyle ตามที่จำได้ / นึกออกไปก่อนแล้วมาจัด section หรือทำความสะอาดโค้ดทีหลัง
ลำบากและเสียเวลามากกว่าการวางแผนก่อนเริ่มเขียนโค้ด

สิ่งที่อยากปรับปรุงหรือเพิ่มในอนาคต

ถ้าเป็นไปได้อยากตกแต่งให้น่าสนใจ และปรับปรุงโค้ดให้มีประสิทธิภาพมากขึ้น
เพราะจะได้นำความรู้ใหม่มาประยุกต์ใช้ และฝึกฝนฝีมือให้เก่งขึ้น
